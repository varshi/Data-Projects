
# 🍽️ Zomato Data Analysis

This project analyzes customer behavior and restaurant trends using Zomato's food delivery dataset. It uses Python to clean, visualize, and extract insights that answer key business questions.

---

## 📊 Project Objective

To perform data analysis and visualization on Zomato order data to uncover trends in restaurant types, customer preferences, spending behavior, and more.

---

## ❓ Business Questions Answered

1. **What type of restaurant do the majority of customers order from?**
2. **How many votes has each type of restaurant received from customers?**
3. **What are the ratings that the majority of restaurants have received?**
4. **What is the average spending on each order by couples ordering online?**
5. **Which mode (online or offline) has received the highest rating?**
6. **Which type of restaurant receives more offline orders?**

---

## 🔍 Key Steps in the Notebook

- **Importing and reading data:** Load the dataset using `pandas`
- **Data cleaning:** Clean up columns like `rate` and `approx_cost(for two people)` to ensure they're usable for analysis
- **EDA & Visualization:** Use bar plots, pie charts, and value counts to explore data
- **Insights & Interpretation:** Each business question is answered with both code and clear visuals

---

## ✅ Tools Used

- Python
- Jupyter Notebook
- pandas, numpy
- matplotlib, seaborn

---

## 📌 How to Run

1. Download or clone the repo
2. Open `Zomato_Data_Analysis.ipynb` in Jupyter Notebook
3. Make sure `Zomato data .csv` is in the same folder
4. Run all cells to see analysis and output
